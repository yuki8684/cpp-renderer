## 3. ★★ 主线：(α, β) 这一个概念，被用了 4 次

**如果只记住一件事，记这个。**

`Quad` 的参数化是 `P = Q + α·u + β·v`。
`Triangle(a,b,c)` 构造时传的是 `Quad(a, b−a, c−a, mat)`，所以：

```
P = a + α(b−a) + β(c−a) = (1−α−β)·a + α·b + β·c
                           └─w_a──┘   └w_b┘  └w_c┘
```

**`(α, β)` 就是重心坐标。** 它在这几天出场了四次，每次穿不同衣服：

| 天 | 用途 | 代码位置 | 关键细节 |
|:--:|---|---|---|
| **13** | **判断点在不形状里** | `Quad::is_interior(a,b)` | 平行四边形 `0≤a≤1, 0≤b≤1`；三角形 `a≥0, b≥0, a+b≤1` —— **换形状只改这一个函数** |
| **15** | **插值法线** | `Triangle::set_hit_normal` | `w_a·n0 + α·n1 + β·n2`，**最后必须 `unit_vector`** |
| **22** | **插值 UV** | 同上（`if (has_uv)` 分支） | `w_a·uv0 + α·uv1 + β·uv2`，**不能归一化** |
| **22** | **当兜底 UV 用** | `Quad::set_hit_normal` 里 `rec.u=alpha; rec.v=beta` | 没有 `vt` 时就用它 —— **能用但永远不对** |

### 为什么"三个一组"

`tri_indices` 每 3 个一组、`tri_uvs` 每 3 个一组、顶点法线也是每三角形 3 个 ——
**因为一个三角形有 3 个角，每个角上挂一套属性（位置 / 法线 / UV）。**

```
tri_indices[3k+0], [3k+1], [3k+2]   → 第 k 个三角形的三个角
        ↓ 同一个下标
positions[ ]  normals[ ]  tri_uvs[ ]
```

**位置、法线、UV 都挂在"角"上，不是挂在"三角形"上。** 这是理解 Day 20–22 的钥匙。
